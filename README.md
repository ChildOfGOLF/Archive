# Archive

Archive — это WPF-приложение для работы с ZIP-архивами, разработанное с использованием C# и библиотеки SharpCompress.

## Возможности
- Открытие и просмотр содержимого ZIP-архивов  
- Извлечение файлов в указанную директорию  
- Создание ZIP-архивов из папок  
- Встроенный файловый проводник на основе TreeView  

## Технологии
- C#  
- WPF  
- MahApps.Metro  
- SharpCompress  

## Установка и запуск
1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/ChildOfGOLF/Archive.git
   ```
2. Откройте проект в Visual Studio  
3. Соберите и запустите проект  

## Структура проекта
- `MainWindow.xaml` / `MainWindow.xaml.cs` — основной интерфейс и логика управления  
- `FileExplorerWindow.xaml` / `FileExplorerWindow.xaml.cs` — файловый проводник  
- `ArchiveManager.cs` — обработка архивов с использованием SharpCompress  

## Использование
- **Открытие архива**: выберите ZIP-файл и просмотрите его содержимое  
- **Извлечение архива**: выберите архив и укажите папку для распаковки  
- **Создание архива**: выберите папку и сохраните её в ZIP-формате
